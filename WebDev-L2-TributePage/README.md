# OIBSIP Level 2 - Tribute Page

## About

This project is a responsive tribute page dedicated to Dr. A. P. J. Abdul Kalam.

It was created as part of my OASIS INFOBYTE Web Development Internship - Level 2.

The page presents his background, important milestones, achievements, inspirational message and legacy.

## Features

* Responsive hero section
* Dr. A. P. J. Abdul Kalam biography
* Prominent Wikimedia Commons image
* Important milestones timeline
* Inspirational quote section
* Legacy section
* Responsive design
* Multiple background colours
* Multiple font styles
* Smooth navigation

## Technologies Used

* HTML5
* CSS3
* Google Fonts
