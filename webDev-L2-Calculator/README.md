# OIBSIP Level 2 - Calculator

## About

This is a responsive calculator developed as part of my OASIS INFOBYTE Web Development Internship.

The project performs basic arithmetic operations through a simple and user-friendly interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number support
* Clear button
* Delete/Backspace button
* Operator chaining
* Division-by-zero handling
* Keyboard support
* Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
WebDev-L2-Calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a web browser.
4. Use the calculator to perform arithmetic operations.
