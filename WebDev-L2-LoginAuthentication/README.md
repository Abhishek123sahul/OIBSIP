# Login Authentication System

A simple and responsive frontend Login Authentication System developed as part of the OASIS INFOBYTE Web Development Internship – Level 2, Task 4.

## Project Overview

This project provides a basic authentication system where users can create an account and securely log in to a protected dashboard.

The application uses HTML, CSS, JavaScript, LocalStorage, and SHA-256 hashing for password storage.

## Features

- User registration
- Username validation
- Email validation
- Password validation
- Minimum 8-character password requirement
- Password must contain at least one number
- Confirm password validation
- Duplicate email checking
- Login authentication
- Generic incorrect credential error
- Protected dashboard
- Login session using LocalStorage
- Logout functionality
- SHA-256 password hashing
- Responsive design
- Basic form validation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Web Crypto API
