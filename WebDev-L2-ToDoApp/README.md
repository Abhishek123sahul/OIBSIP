# To-Do Web App

A simple and responsive To-Do Web App developed as part of the OASIS INFOBYTE Web Development Internship.

## Features

- Add new tasks
- View pending tasks
- View completed tasks
- Mark tasks as completed
- Undo completed tasks
- Edit tasks inline
- Delete tasks
- Display pending and completed task counts
- Empty-state messages
- Task creation timestamps
- LocalStorage persistence
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage
